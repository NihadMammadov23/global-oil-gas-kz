Sənaye &
Kimyəvi Məhsullar

SOCAR və iri sənaye müəssisələrinə xidmət göstərən geniş çeşidli kimyəvi xammallar, qazma mayeləri, sənaye avadanlıqları və ehtiyat hissələri kataloqu.

Kateqoriya:

Kimyəvi Xammallar

Sənaye prosesləri üçün sertifikatlı xammallar

Ən çox tələb olunan

Hidrogen Peroksid (H₂O₂)

Sənaye proseslərində ağardıcı, oksidləşdirici və dezinfeksiyaedici kimi istifadə edilən yüksək keyfiyyətli H₂O₂.

  • Konsentrasiya: 35%, 50%, 60%
  • Çatdırılma: 1–200 kq konteyner
Sorğu göndər

Natrium Hidroksid (NaOH)

Qida, kağız, tekstil və kimya sənayesinin əvəzsiz xammalı olan texniki dərəcəli NaOH.

  • Forma: Bərk flake / 50% məhlul
  • Keyfiyyət: Texniki dərəcəli
  • Qablaşdırma: 25 kq çuval / IBC
Sorğu göndər

Xlorid Turşusu (HCl)

Metal təmizlənməsi, su müalicəsi və kimyəvi sintez üçün texniki keyfiyyətli xlorid turşusu.

  • Konsentrasiya: 30–36%
  • Rəng: Şəffaf / sarımtıl
  • Çatdırılma: Sistern / IBC
Sorğu göndər

Kükürd Turşusu (H₂SO₄)

Gübrə istehsalı, metal emalı və kimya proseslərindən ötrü sertifikatlı sulfat turşusu.

  • Konsentrasiya: 93–98%
  • İSTM / GOST standartlara uyğun
  • Çatdırılma: Paslanmaz sistern
Sorğu göndər

Natrium Karbonat (Na₂CO₃)

Şüşə, sabun, detercan istehsalında geniş istifadə olunan texniki ağır soda.

  • Keyfiyyət: Texniki dərəcəli
  • Xassə: ≥99.2% Na₂CO₃
  • Qablaşdırma: 25 kq çuval / bigbag
Sorğu göndər

İzopropil Spirt (IPA)

Elektronika, tibb, kimya sənayesi üçün yüksək keyfiyyətli texniki dərəcəli IPA.

  • Keyfiyyət: ≥99.7% (ACS dərəcə)
  • Qablaşdırma: 25L / 200L / IBC
  • COA hər partiyada verilir
Sorğu göndər

Qazma Məhsulları

Neft-qaz qazma əməliyyatları üçün xüsusi kimyəvi kompozisiyalar

Qazma Mayesi Qatqıları

Qazma sürətini artıran, baltanı qoruyan və lay sabitliyini təmin edən kimyəvi qatqılar paketi.

  • Su əsaslı / Yağ əsaslı sistem
  • Yüksək temp. davamlılıq (180°C+)
Sorğu göndər

Barit (BaSO₄)

Qazma mayesinin sıxlığını artıran API 13A standartına uyğun barit tozu.

  • Spesifik çəki: ≥4.20 g/cm³
  • API 13A Spec uyğun
  • Qablaşdırma: 25 kq / bigbag
Sorğu göndər Stokda

Sement Qatqıları

Quyu sementlənməsini optimallaşdıran sürətləndiricilər, ləngidiciclər və sıxlıq tənzimləyiciləri.

  • Dərinlik: 0–6000 m
  • Texniki dəstək ilə birlikdə
Sorğu göndər

Sənaye Avadanlığı

Neft-qaz, kimya və istehsalat sektoru üçün texniki avadanlıq

Sənaye Boruları və Fitinqlər

Yüksək təzyiq və temperatur üçün sertifikatlı çelik, polietilen və pas tutmayan boru sistemləri.

  • Diametr: DN 15 – DN 600
  • Material: CS / SS / HDPE
  • ASME / EN standartlarına uyğun
Sorğu göndər

Klapan və Armatur

Gate, ball, check və butterfly tipli sənaye klapanları – xam neft, qaz, kimyəvi mühit uyğun.

  • Təzyiq sinfi: Class 150–2500
  • Material: WCB / SS316 / Duplex
  • API 6D / API 608 sertifikatları
Sorğu göndər

Sənaye Nasosları

Maye, kimyəvi və abraziv mühit üçün mərkəzdənqaçma, dişli və membran nasosları.

  • Axın: 1–1000 m³/saat
  • Temperatura davamlılıq: -20°C–200°C
  • ATEX sertifikatı mövcuddur
Sorğu göndər

Fərdi Mühafizə Vasitələri

Kimyəvi, mexaniki və istilik risklərindən qorunan standart PPE dəstləri.

  • Kimyəvi müqavimətli əlcəklər
  • Toplu və fərdi sifariş
Sorğu göndər

Kimyəvi Saxlama Konteynerlər

Turşu, qələvi və yanıcı kimyəvilərin təhlükəsiz saxlanması üçün HDPE / polipropilen konteyner çeşidi.

  • Həcm: 20L – 1000L (IBC)
  • UN sertifikatlı
  • ADR nəqliyyat uyğunluğu
Sorğu göndər

Ehtiyat Hissələri

Kritik avadanlıq üçün orijinal və uyğun ehtiyat hissələri

Sızdırmazlıq Elementləri (Seallar)

O-ring, mekanik seal, qazma baldaqlığı üçün yüksək temperatur davamlı sızdırmazlıq elementləri.

  • Material: VITON / NBR / EPDM / PTFE
  • Temp.: -60°C dən +260°C-yə
  • Standart və xüsusi ölçülər
Sorğu göndər

Sənaye Döşəmə Örtükləri

Kimyəvi mühit üçün Viton, neopren, PTFE döşəmə möhürleyici materiallar.

  • Qalınlıq: 1–25 mm
  • PN16–PN100 flans uyğunluğu
  • Xüsusi kəsim xidməti mövcud
Sorğu göndər

Nasoslar üçün Mexaniki Seallar

Grundfos, Flowserve, KSB, Ebara tipli nasoslar üçün uyğun mexaniki sızdırmazlıq hissələri.

  • Üz material: SiC / Carbon / TC
  • Standart: EN 12756 / DIN 24960
  • Sifarişlə 3–5 iş günü
