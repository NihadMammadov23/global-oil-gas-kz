İşlədiyimiz Sənaye Mineralları

Neft-qaz, tikinti, kimya və digər sənaye sahələri üçün ehtiyac duyulan geniş çeşidli minerallar üyüdülür və emal edilir.

Barit (BaSO₄)

Qazma mayelərinin sıxlığını artırmaq üçün API 13A standartına uyğun barit tozu. ≥4.20 g/cm³ spesifik çəki.

API 13A Sertifikatlı
Mərmər (CaCO₃)

Tikinti, boyaqçılıq, plastik və kağız sənayesi üçün müxtəlif incəlik dərəcələrində mərmər tozu.

Çoxsahəli İstifadə
Kalsit

Sement, boyaq, plastik sənayesi üçün yüksək keyfiyyətli kalsit tozu. Müxtəlif fraksiya ölçüləri mövcuddur.

Yüksək Keyfiyyət
Digər Minerallar

Dolomit, silikat, feldspat, talk və digər sənaye minerallarının xüsusi tələblərə uyğun emalı.

Fərdi Sifariş
Proses

Başdan-başa Emal Xidməti

İstehsalat istiqamətinin genişləndirilməsi çərçivəsində şirkət 2026-cı ilin ikinci yarısında neft-servis, tikinti, sənaye və digər əlaqəli sahələrdə istifadə olunan sənaye materiallarının üyüdülməsi üzrə istehsal xəttini işə salır. Əsas diqqət barit, mərmər və digər mineral xammalların emalı və tələb olunan texniki göstəricilərə uyğun hazırlanmasına yönəldiləcək.

  • İstehsal prosesi sifarişçilərin tələblərinə uyğun fraksiyada, stabil texniki xüsusiyyətlərə və yüksək keyfiyyət göstəricilərinə malik materialların əldə edilməsinə istiqamətlənəcək. Bizim üçün xammalın seçilməsindən və üyüdülməsindən başlayaraq, hazır məhsulun qablaşdırılması və çatdırılmasına qədər hər bir mərhələdə keyfiyyətə nəzarət xüsusi əhəmiyyət daşıyır.

Bu istiqamətin işə salınması şirkətə istehsal imkanlarını genişləndirməyə, müştəriləri tələb olunan sənaye materialları ilə təmin etməyə və təchizat prosesində daha çevik yanaşma təqdim etməyə imkan verəcək. Sənaye materiallarının üyüdülməsi və hazırlanması üzrə sifarişlər artıq qəbul olunur. Biz sifarişçilərin ehtiyaclarını əvvəlcədən nəzərdən keçirməyə, texniki tələbləri razılaşdırmağa və neft-qaz, sənaye və regional layihələr üçün optimal əməkdaşlıq şərtləri formalaşdırmağa hazırıq.
